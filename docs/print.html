크롬 웹브라우저에서 북마크 만들기

시험 중 엉뚱한 URL에 접속해 불필요한 오해를 사지 않도록 웹브라우저에 미리 북마크를 만들어 놓자.

북마크는 총 2개 만들어 놓는다.

  1. AI 서비스(chatGPT, gemini, claude 등)

  2. 배포 서비스(netlify 등)

북마크 만들기

  1. 크롬 웹브라우저에서 점 3개 버튼을 누른다.

  2. “북마크 및 목록” 메뉴를 선택한다.

  3. “북마크바 표시” 메뉴를 선택한다.


AI 서비스에 접속한 다음(여기서는 gemini에 접속),

URL 앞 (사이트 정보보기) 버튼을 북마크쪽으로 끌어 내린다.


북마크가 생성된다.

시험 중에는 이 북마크를 클릭해 빠르고 정확하게 해당 사이트로 이동한다.

Visual Studio Code

visual studio code는 윈도우의 메모장과 비슷한 텍스트 에디터(text editor)이다.

Microsoft가 관리하고, 개발에 도움주는 다양한 기능이 추가된 텍스트 에디터이다.


AI 챔피언 그린, 블루 단계는 모두 visual studio code 를 이용해 작업한다.

visual studio code는 AI 챔피언 그린 등급 학습 중 다음의 용도로 사용한다.

  • md 파일 읽기
  • 코딩

Visual Studio Code 설치

설치 파일 다운로드

다음의 사이트에서 설치파일을 다운로드 한다.

https://code.visualstudio.com

“Download for Windows” 버튼을 클릭해 설치 파일을 다운로드한다.

다운로드받은 설치 파일을 실행한다.

설치 옵션

설치 옵션이 나오면 위 4개의 옵션은 모두 체크하고 설치한다.

이후는 모두 [다음] 버튼을 눌러 설치한다.

live server 설치

live server는 visual studio code(이하 vscode)에서 실행되는 확장 프로그램(플러그인)이다.

웹서버에 html 파일을 보내지 않아도 vscode 자체에서 웹서버에서 실행한 것과 같은 효과를 내주는 매우 편한 확장 프로그램이다.

확장 프로그램 설치

vscode의 왼쪽 사이드 바에서 확장 아이콘을 누른다.

live server로 검색한다.

설치 버튼을 누른다.

Visual Studio Code에서 .md파일 보기

최신 visual studio code(이하 vscode)에는 기본적으로 markdown 파일을 제대로 보여주는 기능이 내장되어 있다.

mardkdown 파일을 보는데 익숙하지 않다면 아래의 방법으로 markdown 파일을 읽어보자.(권장)

.md 파일(markdown)이 있는 폴더 열기

vscode는 파일 하나씩 여는 것 뿐 아니라 한 폴더안에 있는 모든 파일을 쉽게 열 수 있도록 되어 있다. 이 방법은 훨씬 편하게 작업하도록 도와준다.

탐색기에서 다음과 같이 실행한다.

  1. 탐색기에서 md 파일이 있는 폴더의 아래 쪽 빈 공간을 오른쪽 클릭한다.

  2. “Code(으)로 열기” 버튼을 누른다.

vscode에서 .md 파일 열어 보기

  1. 왼쪽에서 md 파일을 더블클릭한다. (오른쪽 창에 파일 내용이 나타난다.)

  2. 미리보기 버튼을 클릭한다.

.md 파일 미리보기

오른쪽에 md 파일의 내용이 나타난다.

Visual Studio Code에서 live server를 이용해 html 실행

.html 파일이 있는 폴더 열기

vscode는 파일 하나씩 여는 것 뿐 아니라 한 폴더안에 있는 모든 파일을 쉽게 열 수 있도록 되어 있다. 이 방법은 훨씬 편하게 작업하도록 도와준다.

탐색기에서 다음과 같이 실행한다.

  1. 탐색기에서 html 파일이 있는 폴더의 아래 쪽 빈 공간을 오른쪽 클릭한다.

  2. “Code(으)로 열기” 버튼을 누른다.

visual studio code에서 html 파일 실행하기

  1. html 파일을 오른쪽 클릭한다.

  2. 팝업 메뉴에서 “Open With Live Server“를 선택한다.

브라우저가 열리면서 해당 html 파일의 내용이 실행된다.

웹서버에 배포

AI가 만들어 준 index.html 파일은 내 컴퓨터에만 저장되어 있다.

전 세계 모든 사람들이 이 HTML 파일을 웹브라우저를 통해 보게 하고 싶은데 내 컴퓨터에만 파일이 있으면 다른 사람들은 (보안상의 이유로라도) 이 파일을 열어볼 수가 없다.

그래서 이 index.html 파일을 웹서버에 업로드해서 모든 사람들이 이 index.html 파일에 접근할 수 있도록 해야 한다.

웹서버

웹서버에 업로드하려면 웹서버를 구입하고, 설치, 운영해야 한다.

상당한 비용과 운영인력까지 필요하다.

그런데 이런 일들을 깔끔하게 처리해주는 서비스들이 있다.

대표적인 곳이

  • netlify
  • vercel
  • github pages
  • render
  • firebase hosting
  • cloudflare pages

등이다.

netlify

여기서 우리는 netlify를 이용한 배포를 해 보자.

테스트는 무료이고 유료 요금도 월 $9, $20 정도이다.

회원가입, 로그인

https://netlify.com에 접속하고 회원가입, 로그인한다.

새 프로젝트 생성

netlify 상단 메뉴에서 dashboard로 이동한다.

Add new projects 버튼을 누른다.

새 프로젝트에 index.html 파일 업로드

index.html 파일을 netlify 웹페이지의 Upload you project files 부분에 끌어다 놓는다. 끝.

이 하나로 웹서버에 업로드하는 게 끝난다. 잠시 후 화면이 아래와 같이 바뀐다.

표시한 부분이 전 세계에서(핸드폰에서도 가능) 접속할 수 있는 url 주소이다.

url 변경 = project 이름 변경

url이 복잡한데 url은 project 이름을 따라가도록 되어 있다. 그래서 project 이름을 변경하면 더 짧은 주소로 접근할 수 있게 된다.

project 이름을 변경하는 방법은, 위 이미지에서 “Project configuration” 버튼을 눌러 안으로 들어간 화면에서 “Change project name“을 누르는 것이다.

<script>
    // Web Audio API 기반 효과음 생성기 (외부 소스 의존 없음)
    class SoundEffects {
        constructor() {
            this.ctx = null;
        }

        init() {
            if (!this.ctx) {
                this.ctx = new (window.AudioContext || window.webkitAudioContext)();
            }
        }

        playClick() {
            if (!this.ctx) return;
            const osc = this.ctx.createOscillator();
            const gain = this.ctx.createGain();
            osc.type = 'sine';
            osc.frequency.setValueAtTime(600, this.ctx.currentTime);
            osc.frequency.exponentialRampToValueAtTime(200, this.ctx.currentTime + 0.05);
            gain.gain.setValueAtTime(0.15, this.ctx.currentTime);
            gain.gain.exponentialRampToValueAtTime(0.01, this.ctx.currentTime + 0.05);
            osc.connect(gain);
            gain.connect(this.ctx.destination);
            osc.start();
            osc.stop(this.ctx.currentTime + 0.05);
        }

        playFlag() {
            if (!this.ctx) return;
            const osc = this.ctx.createOscillator();
            const gain = this.ctx.createGain();
            osc.type = 'triangle';
            osc.frequency.setValueAtTime(300, this.ctx.currentTime);
            osc.frequency.exponentialRampToValueAtTime(800, this.ctx.currentTime + 0.08);
            gain.gain.setValueAtTime(0.2, this.ctx.currentTime);
            gain.gain.exponentialRampToValueAtTime(0.01, this.ctx.currentTime + 0.08);
            osc.connect(gain);
            gain.connect(this.ctx.destination);
            osc.start();
            osc.stop(this.ctx.currentTime + 0.08);
        }

        playExplosion() {
            if (!this.ctx) return;
            // 노이즈 버퍼 생성으로 폭발음 연출
            const bufferSize = this.ctx.sampleRate * 0.4;
            const buffer = this.ctx.createBuffer(1, bufferSize, this.ctx.sampleRate);
            const data = buffer.getChannelData(0);
            for (let i = 0; i < bufferSize; i++) {
                data[i] = Math.random() * 2 - 1;
            }

            const noise = this.ctx.createBufferSource();
            noise.buffer = buffer;

            const filter = this.ctx.createBiquadFilter();
            filter.type = 'lowpass';
            filter.frequency.setValueAtTime(800, this.ctx.currentTime);
            filter.frequency.linearRampToValueAtTime(50, this.ctx.currentTime + 0.4);

            const gain = this.ctx.createGain();
            gain.gain.setValueAtTime(0.5, this.ctx.currentTime);
            gain.gain.exponentialRampToValueAtTime(0.01, this.ctx.currentTime + 0.4);

            noise.connect(filter);
            filter.connect(gain);
            gain.connect(this.ctx.destination);

            noise.start();
        }

        playWin() {
            if (!this.ctx) return;
            const notes = [440, 554.37, 659.25, 880]; // A4, C#5, E5, A5 멜로디
            notes.forEach((freq, index) => {
                const osc = this.ctx.createOscillator();
                const gain = this.ctx.createGain();
                osc.type = 'sine';
                osc.frequency.setValueAtTime(freq, this.ctx.currentTime + index * 0.1);
                gain.gain.setValueAtTime(0.2, this.ctx.currentTime + index * 0.1);
                gain.gain.exponentialRampToValueAtTime(0.01, this.ctx.currentTime + index * 0.1 + 0.25);
                osc.connect(gain);
                gain.connect(this.ctx.destination);
                osc.start(this.ctx.currentTime + index * 0.1);
                osc.stop(this.ctx.currentTime + index * 0.1 + 0.25);
            });
        }
    }

    const sound = new SoundEffects();

    // 게임 환경 설정
    const DIFFICULTIES = {
        easy: { width: 9, height: 9, mines: 10 },
        medium: { width: 16, height: 16, mines: 40 },
        hard: { width: 30, height: 16, mines: 99 }
    };

    let currentDifficulty = 'easy';
    let config = { ...DIFFICULTIES.easy };

    // 게임 상태 상태 변수
    let board = [];
    let isFirstClick = true;
    let isGameOver = false;
    let isGameWon = false;
    let remainingMines = 0;
    let revealedCount = 0;
    let timer = 0;
    let timerInterval = null;
    let flagMode = false; // 터치 기기용 깃발 배치 모드

    // DOM 요소
    const boardEl = document.getElementById('board');
    const mineCounterEl = document.getElementById('mine-counter');
    const timerEl = document.getElementById('timer');
    const faceBtn = document.getElementById('face-btn');

    // 게임 초기화
    function initGame() {
        // 타이머 초기화
        clearInterval(timerInterval);
        timerInterval = null;
        timer = 0;
        timerEl.textContent = '000';

        isFirstClick = true;
        isGameOver = false;
        isGameWon = false;
        revealedCount = 0;
        remainingMines = config.mines;

        faceBtn.textContent = '😊';
        updateMineCounter();

        // 데이터 보드 구조 생성
        board = Array(config.height).fill(null).map(() => 
            Array(config.width).fill(null).map(() => ({
                isMine: false,
                isRevealed: false,
                isFlagged: false,
                adjacentMines: 0
            }))
        );

        renderBoard();
    }

    // 지뢰 배치 (첫 번째 클릭된 셀 및 인접 8개 셀 안전 보장)
    function placeMines(safeR, safeC) {
        let placed = 0;
        while (placed < config.mines) {
            const r = Math.floor(Math.random() * config.height);
            const c = Math.floor(Math.random() * config.width);

            // 안전구역 (첫 클릭 위치와 인접 8개 구역) 제외
            const isSafeZone = Math.abs(r - safeR) <= 1 && Math.abs(c - safeC) <= 1;

            if (!board[r][c].isMine && !isSafeZone) {
                board[r][c].isMine = true;
                placed++;
            }
        }

        // 인접 지뢰 수 계산
        for (let r = 0; r < config.height; r++) {
            for (let c = 0; c < config.width; c++) {
                if (!board[r][c].isMine) {
                    let count = 0;
                    for (let dr = -1; dr <= 1; dr++) {
                        for (let dc = -1; dc <= 1; dc++) {
                            const nr = r + dr;
                            const nc = c + dc;
                            if (nr >= 0 && nr < config.height && nc >= 0 && nc < config.width) {
                                if (board[nr][nc].isMine) count++;
                            }
                        }
                    }
                    board[r][c].adjacentMines = count;
                }
            }
        }
    }

    // UI 보드 레이아웃 그리기
    function renderBoard() {
        boardEl.innerHTML = '';
        boardEl.style.gridTemplateColumns = `repeat(${config.width}, minmax(0, 1fr))`;

        // 셀 크기 조절 (상급일수록 작은 셀 크기 적용)
        let cellSizeClass = 'w-7 h-7 text-sm sm:w-9 sm:h-9 sm:text-base';
        if (config.width > 20) {
            cellSizeClass = 'w-6 h-6 text-xs sm:w-7 sm:h-7 sm:text-sm';
        } else if (config.width > 12) {
            cellSizeClass = 'w-6 h-6 text-xs sm:w-8 sm:h-8 sm:text-sm';
        }

        for (let r = 0; r < config.height; r++) {
            for (let c = 0; c < config.width; c++) {
                const cellBtn = document.createElement('button');
                cellBtn.dataset.row = r;
                cellBtn.dataset.col = c;
                cellBtn.className = `cell ${cellSizeClass} rounded font-bold flex items-center justify-center select-none cell-unrevealed`;

                // 모바일 길게 누르기(Long Press) 처리용
                let touchTimer = null;

                cellBtn.addEventListener('mousedown', (e) => {
                    sound.init();
                    if (e.button === 0 && !flagMode && !isGameOver && !board[r][c].isRevealed) {
                        faceBtn.textContent = '😮';
                    }
                });

                cellBtn.addEventListener('mouseup', () => {
                    if (!isGameOver && !isGameWon) faceBtn.textContent = '😊';
                });

                cellBtn.addEventListener('click', (e) => {
                    sound.init();
                    if (isGameOver || isGameWon) return;

                    if (flagMode) {
                        handleRightClick(r, c);
                    } else {
                        handleLeftClick(r, c);
                    }
                });

                // 우클릭 깃발 토글
                cellBtn.addEventListener('contextmenu', (e) => {
                    e.preventDefault();
                    sound.init();
                    if (isGameOver || isGameWon) return;
                    handleRightClick(r, c);
                });

                // 터치 이벤트 지원 (길게 터치시 깃발)
                cellBtn.addEventListener('touchstart', (e) => {
                    sound.init();
                    if (isGameOver || isGameWon) return;
                    touchTimer = setTimeout(() => {
                        handleRightClick(r, c);
                        touchTimer = null;
                    }, 400);
                }, { passive: true });

                cellBtn.addEventListener('touchend', () => {
                    if (touchTimer) {
                        clearTimeout(touchTimer);
                        touchTimer = null;
                    }
                });

                boardEl.appendChild(cellBtn);
            }
        }
    }

    // 왼쪽 클릭 (셀 오픈)
    function handleLeftClick(r, c) {
        const cell = board[r][c];

        if (cell.isFlagged || cell.isRevealed) return;

        // 첫번째 클릭 처리 (안전지대 보장 및 타이머 시작)
        if (isFirstClick) {
            isFirstClick = false;
            placeMines(r, c);
            startTimer();
        }

        // 지뢰 밟음 -> 패배
        if (cell.isMine) {
            triggerGameOver(r, c);
            return;
        }

        sound.playClick();
        revealCell(r, c);

        // 승리 체크
        checkWinCondition();
    }

    // 재귀적 셀 오픈 (빈 공간 재귀적 탐색 - Flood Fill)
    function revealCell(r, c) {
        const cell = board[r][c];
        if (cell.isRevealed || cell.isFlagged) return;

        cell.isRevealed = true;
        revealedCount++;

        const el = getCellElement(r, c);
        el.classList.remove('cell-unrevealed');
        el.classList.add('cell-revealed', 'animate-pop');

        if (cell.adjacentMines > 0) {
            el.textContent = cell.adjacentMines;
            el.classList.add(`num-${cell.adjacentMines}`);
        } else {
            // 인접 지뢰가 0개인 경우 주변 8칸 자동 오픈
            for (let dr = -1; dr <= 1; dr++) {
                for (let dc = -1; dc <= 1; dc++) {
                    const nr = r + dr;
                    const nc = c + dc;
                    if (nr >= 0 && nr < config.height && nc >= 0 && nc < config.width) {
                        if (!board[nr][nc].isRevealed) {
                            revealCell(nr, nc);
                        }
                    }
                }
            }
        }
    }

    // 우클릭 (깃발 토글)
    function handleRightClick(r, c) {
        const cell = board[r][c];
        if (cell.isRevealed) return;

        cell.isFlagged = !cell.isFlagged;
        const el = getCellElement(r, c);

        if (cell.isFlagged) {
            remainingMines--;
            el.textContent = '🚩';
            sound.playFlag();
        } else {
            remainingMines++;
            el.textContent = '';
        }

        updateMineCounter();
    }

    // 게임 오버 처리
    function triggerGameOver(hitR, hitC) {
        isGameOver = true;
        clearInterval(timerInterval);
        faceBtn.textContent = '😵';
        sound.playExplosion();

        // 전체 지뢰 공개 및 잘못된 깃발 표시
        for (let r = 0; r < config.height; r++) {
            for (let c = 0; c < config.width; c++) {
                const cell = board[r][c];
                const el = getCellElement(r, c);

                if (r === hitR && c === hitC) {
                    el.textContent = '💥';
                    el.classList.remove('cell-unrevealed');
                    el.classList.add('bg-red-600', 'animate-explode');
                } else if (cell.isMine && !cell.isFlagged) {
                    el.textContent = '💣';
                    el.classList.remove('cell-unrevealed');
                    el.classList.add('cell-revealed');
                } else if (!cell.isMine && cell.isFlagged) {
                    el.textContent = '❌';
                    el.classList.remove('cell-unrevealed');
                    el.classList.add('bg-red-100');
                }
            }
        }
    }

    // 승리 조건 체크
    function checkWinCondition() {
        const totalSafeCells = (config.width * config.height) - config.mines;
        if (revealedCount === totalSafeCells) {
            isGameWon = true;
            clearInterval(timerInterval);
            faceBtn.textContent = '😎';
            sound.playWin();

            // 남아있는 지뢰에 자동 깃발 표시
            for (let r = 0; r < config.height; r++) {
                for (let c = 0; c < config.width; c++) {
                    if (board[r][c].isMine) {
                        board[r][c].isFlagged = true;
                        const el = getCellElement(r, c);
                        el.textContent = '🚩';
                    }
                }
            }
            remainingMines = 0;
            updateMineCounter();

            // 최고 기록 업데이트 저장
            saveHighScore(currentDifficulty, timer);
        }
    }

    // 헬퍼: 셀 DOM 엘리먼트 가져오기
    function getCellElement(r, c) {
        return boardEl.querySelector(`[data-row="${r}"][data-col="${c}"]`);
    }

    // 지뢰 표시기 업데이트
    function updateMineCounter() {
        const formatted = String(Math.max(-99, remainingMines)).padStart(3, '0');
        mineCounterEl.textContent = formatted;
    }

    // 타이머 동작
    function startTimer() {
        timerInterval = setInterval(() => {
            timer++;
            if (timer > 999) timer = 999;
            timerEl.textContent = String(timer).padStart(3, '0');
        }, 1000);
    }

    // 난이도 설정 변경
    function setDifficulty(diff) {
        currentDifficulty = diff;
        config = { ...DIFFICULTIES[diff] };

        // 난이도 버튼 UI 업데이트
        ['easy', 'medium', 'hard', 'custom'].forEach(d => {
            const btn = document.getElementById(`btn-${d}`);
            if (d === diff) {
                btn.className = "px-2.5 py-1.5 text-xs sm:text-sm font-semibold rounded-lg bg-indigo-600 text-white shadow hover:bg-indigo-500 transition";
            } else {
                btn.className = "px-2.5 py-1.5 text-xs sm:text-sm font-semibold rounded-lg bg-slate-700 text-slate-300 hover:bg-slate-600 transition";
            }
        });

        initGame();
    }

    // 터치 기기용 깃발 모드 토글
    function toggleFlagMode() {
        flagMode = !flagMode;
        const btn = document.getElementById('flag-mode-btn');
        const text = document.getElementById('flag-mode-text');
        const icon = document.getElementById('flag-mode-icon');

        if (flagMode) {
            btn.classList.replace('bg-slate-800', 'bg-indigo-900/60');
            btn.classList.replace('border-slate-700', 'border-indigo-500');
            text.textContent = '깃발';
            text.className = 'text-amber-400 font-bold';
            icon.textContent = '🚩';
        } else {
            btn.classList.replace('bg-indigo-900/60', 'bg-slate-800');
            btn.classList.replace('border-indigo-500', 'border-slate-700');
            text.textContent = '열기';
            text.className = 'text-indigo-400 font-bold';
            icon.textContent = '🔍';
        }
    }

    // 사용자 지정 난이도 모달 로직
    function openCustomModal() {
        document.getElementById('custom-modal').classList.remove('hidden');
        document.getElementById('custom-modal').classList.add('flex');
    }

    function closeCustomModal() {
        document.getElementById('custom-modal').classList.add('hidden');
        document.getElementById('custom-modal').classList.remove('flex');
    }

    function applyCustomSettings() {
        const w = parseInt(document.getElementById('custom-width').value) || 10;
        const h = parseInt(document.getElementById('custom-height').value) || 10;
        let m = parseInt(document.getElementById('custom-mines').value) || 10;

        const clampedW = Math.min(Math.max(w, 9), 30);
        const clampedH = Math.min(Math.max(h, 9), 24);
        const maxMines = Math.floor((clampedW * clampedH) * 0.8); // 최대 80% 밀도 제한
        const clampedMines = Math.min(Math.max(m, 1), maxMines);

        config = { width: clampedW, height: clampedH, mines: clampedMines };
        currentDifficulty = 'custom';

        ['easy', 'medium', 'hard'].forEach(d => {
            document.getElementById(`btn-${d}`).className = "px-2.5 py-1.5 text-xs sm:text-sm font-semibold rounded-lg bg-slate-700 text-slate-300 hover:bg-slate-600 transition";
        });
        document.getElementById('btn-custom').className = "px-2.5 py-1.5 text-xs sm:text-sm font-semibold rounded-lg bg-indigo-600 text-white shadow hover:bg-indigo-500 transition";

        closeCustomModal();
        initGame();
    }

    // 최고 기록 관리 (LocalStorage)
    function saveHighScore(diff, time) {
        if (diff === 'custom') return;
        const key = `minesweeper_best_${diff}`;
        const currentBest = localStorage.getItem(key);

        if (!currentBest || time < parseInt(currentBest)) {
            localStorage.setItem(key, time);
            setTimeout(() => {
                alert(`🎉 축하합니다! ${diff === 'easy' ? '초급' : diff === 'medium' ? '중급' : '상급'} 신기록 달성: ${time}초`);
            }, 100);
        }
    }

    function openScoresModal() {
        ['easy', 'medium', 'hard'].forEach(d => {
            const best = localStorage.getItem(`minesweeper_best_${d}`);
            document.getElementById(`score-${d}`).textContent = best ? `${best}초` : '기록 없음';
        });
        document.getElementById('scores-modal').classList.remove('hidden');
        document.getElementById('scores-modal').classList.add('flex');
    }

    function closeScoresModal() {
        document.getElementById('scores-modal').classList.add('hidden');
        document.getElementById('scores-modal').classList.remove('flex');
    }

    // 페이지 로드시 게임 시작
    window.onload = () => {
        initGame();
    };
</script>
